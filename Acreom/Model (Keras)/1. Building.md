4.1 ✧ Begin with a Simple Model: SimpySim
Building a model that takes protein sequences (and any additional features) as input and predicts LLPS propensity.

Layers in SimpySim:
1. **Embedding Layer**: Converts amino acid sequences into dense vectors.
2. **LSTM Layer**: Long Short-Term Memory (LSTM) is used to capture dependencies in the sequence (important for protein structure and function).
3. **Dropout**: Regularization to prevent overfitting. i==s this even a layer -ry==
4. **Dense Output Layer**: Outputs the predicted probability of LLPS occurrence (binary classification in this case).


simpysim_v1.py
```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Embedding, LSTM, Dropout, Input
from tensorflow.keras.optimizers import Adam

# Define the input
sequence_input = Input(shape=(100,), dtype='int32')  # Sequence length of 100, amino acid indices

# Embedding Layer for amino acid sequence

lstm_out = Dropout(0.5)(lstm_out)  # Adding Dropout for regularization
```
