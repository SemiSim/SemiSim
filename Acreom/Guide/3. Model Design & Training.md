## **✦  Deep Learning  (Keras)**
✧ Keras has the robustness of TensorFlow for constructing DNN architecture, but a *much *easier UI to navigate. 
✧ TensorFlow runs on the backend of Keras, so we can use it's capabilities without having to interact with it directly to build our model:)
✧ SemiSim Model specs:
- Input: (Concatenated) feature vectors per protein
- Output: Probability of LLPS under physiological conditions.
- Model: Dense layers with batch norm + dropout. Maybe try Bi-LSTM if we want sequence-dependence.
- Training: Binary classification with class imbalance handling (e.g., focal loss or class weighting)
